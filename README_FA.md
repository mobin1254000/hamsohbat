# 💬 سامانه پیام‌رسان آنلاین «هم‌صحبت»

**هم‌صحبت** یک وب‌اپلیکیشن چت آنلاین، بلادرنگ (Real-time)، امن و کاملاً فارسی است که بر پایه **Node.js**، **Express** و **Socket.IO** پیاده‌سازی شده است.

---

## 🌟 ویژگی‌های کلیدی
- **طراحی مدرن و کاملاً راست‌به‌چپ (RTL):** با فونت فارسی وزیرمتن و رابط کاربری واکنش‌گرا برای موبایل و دسکتاپ.
- **احراز هویت کامل و امن:** ثبت‌نام و ورود کاربران با هش رمزعبور توسط `bcryptjs` و احراز نشست با `JWT`.
- **گفت‌وگوی زنده و دوطرفه:** ارسال و دریافت بلادرنگ پیام با Socket.IO و تفکیک تب‌ها.
- **نشانگر وضعیت آنلاین/آفلاین:** نمایش بلادرنگ کاربران آنلاین با نشانگر سبز.
- **نشانگر وضعیت در حال تایپ (Typing Indicator):** نمایش وضعیت نوشتن مخاطب.
- **تاریخچه گفتگوها:** بازیابی تمام پیام‌های قبلی کاربر از پایگاه‌داده.
- **طراحی دوحالته دیتابیس (Dual-Mode):**
  1. در صورت تنظیم متغیر `DATABASE_URL`، اتصال خودکار به **PostgreSQL** برقرار شده و جداول به صورت خودکار ساخته می‌شوند.
  2. در صورت نبودن دیتابیس، بدون پرتاب خطا در **حافظه موقت (Memory Mode)** اجرا می‌شود.
- **امنیت در کلاینت و سرور:** جلوگیری کامل از حملات XSS با عدم استفاده از `innerHTML` برای داده‌های کاربر و اعتبارسنجی ورودی‌ها در سرور.

## 🚀 راهنمای اجرای محلی (Local)

### پیش‌نیازها:
- نصب بودن **Node.js** (نسخه ۱۸ به بالا)

### مراحل اجرا:
۱. باز کردن پوشه پروژه در ترمینال:
```bash
cd hamsohbat-chat
```

۲. نصب پکیج‌ها:
```bash
npm install
```

۳. ساخت فایل تنظیمات:
```bash
cp .env.example .env
```

۴. اجرای برنامه:
```bash
npm start
```
برنامه در آدرس `http://localhost:3000` در دسترس خواهد بود.

## 🗄️ تنظیم دیتابیس پایدار (PostgreSQL)

برای ذخیره همیشگی اطلاعات، می‌توانید از سرویس‌های ابری رایگان دیتابیس مانند **Supabase** یا **Neon** استفاده کنید:

۱. در [Supabase](https://supabase.com) یا [Neon.tech](https://neon.tech) یک پروژه جدید بسازید.
۲. رشته اتصال (Connection String) با فرمت زیر را دریافت کنید:
```env
DATABASE_URL=postgresql://postgres.xxx:password@aws-0-eu-central-1.pooler.supabase.com:6543/postgres?sslmode=require
```
۳. این مقدار را در فایل `.env` یا بخش Environment Variables سرور قرار دهید.
۴. سرور در هنگام روشن شدن، به صورت خودکار جداول `users` و `messages` را تولید خواهد کرد.

> ⚠️ **توجه مهم درباره حالت بدون دیتابیس (Memory Mode):**
> اگر متغیر `DATABASE_URL` تنظیم نشود، برنامه بدون خطا با حافظه RAM اجرا می‌شود؛ اما با هر بار ری‌استارت شدن سرور، کاربران و پیام‌ها ریست خواهند شد.

## 🌐 راهنمای استقرار رایگان روی Render (Deploy)

۱. پروژه را روی مخزن گیت‌هاب (GitHub) خود Push کنید.
۲. وارد داشبورد [Render.com](https://render.com) شوید و روی **New +** > **Web Service** کلیک کنید.
۳. مخزن گیت‌هاب خود را انتخاب کنید.
۴. تنظیمات زیر را قرار دهید:
   - **Environment:** `Node`
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
5. در بخش **Environment Variables**:
   - کلید `JWT_SECRET` را با یک رشته تصادفی و امن پر کنید.
   - کلید `DATABASE_URL` را با آدرس دیتابیس Postgres خود پر کنید.
۶. روی **Deploy Web Service** کلیک کنید. چت‌روم شما آماده استفاده در بستر اینترنت است!

## 📡 فهرست مسیرهای API

| مسیر | متد | توضیحات |
| :--- | :--- | :--- |
| `/api/register` | `POST` | ثبت‌نام کاربر جدید |
| `/api/login` | `POST` | ورود و دریافت توکن JWT |
| `/api/me` | `GET` | دریافت اطلاعات کاربری جاری با توکن Bearer |
| `/api/users` | `GET` | فهرست سایر کاربران به همراه جستجو |
| `/api/messages/:userId` | `GET` | دریافت تاریخچه پیام‌های کاربر با شناسه مورد نظر |
| `/api/health` | `GET` | بررسی وضعیت سلامت سرور و نوع دیتابیس |
